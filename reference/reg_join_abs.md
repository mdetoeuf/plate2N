# Merge Data from Regression Equation on Standard Curve with Absorbance Data (samples)

Merge Data from Regression Equation on Standard Curve with Absorbance
Data (samples)

## Usage

``` r
reg_join_abs(
  lm_table,
  abs_data,
  target_sp = "N",
  plate_id_col = "plate_id",
  dataset_col = "dataset",
  map_col = "map",
  well_id_col = "well_id",
  value_col = "abs_corrected",
  std_sp_col = "std_sp",
  unit_col = "std_unit"
)
```

## Arguments

- lm_table:

  A tibble with linear model data (as generated by
  [`lm_std_curve()`](https://mdetoeuf.github.io/plate2N/reference/lm_std_curve.md)).
  Must contain columns `plate_id`, `slope`, `adj_r_squared`, `lm_p`
  (linear model) or `plate_id`, `poly_a`, `poly_a_p`, `poly_b`,
  `poly_b_p`, `r_squared`, `adj_r_squared`, `lm_p` (polynomial model)

- abs_data:

  Blank-corrected absorbance data, in a similar format to tidy_plates,
  but containing only sample wells, no empty wells, standard curve wells
  or extractant wells

- target_sp:

  Defaults to "N", the target compound to convert to

- plate_id_col:

  Name of the column identifying physical plates. Defaults to
  `"plate_id"`.

- dataset_col:

  Name of the column identifying the dataset. Defaults to `"dataset"`.

- map_col:

  Name of the column containing well mapping/type information. Defaults
  to `"map"`.

- well_id_col:

  Name of the column identifying wells. Defaults to `"well_id"`.

- value_col:

  Name of the column containing (blank-corrected) absorbance. Defaults
  to `"abs_corrected"`.

- std_sp_col:

  Name of the column identifying the standard species. Defaults to
  `"std_sp"`.

- unit_col:

  Name of the column containing the concentration unit. Defaults to
  `"std_unit"`.

## Value

A tibble joining linear model data with absorbance data

lm_table <- lm_output$lm_data
